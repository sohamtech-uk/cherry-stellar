# Cherry Stellar

Standalone supplier invoices, simulated GBP quotes and Stellar testnet payments with verified reconciliation.

Implementation is on [`feat/stellar-payment-demo`](https://github.com/sohamtech-uk/cherry-stellar/tree/feat/stellar-payment-demo), proposed into `develop`.

See the [setup and demo instructions](https://github.com/sohamtech-uk/cherry-stellar/blob/feat/stellar-payment-demo/README.md).

No Cherry Money private source or history is included. No real money is used.
